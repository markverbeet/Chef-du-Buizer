# Chef du Buizer

Wat eten we de komende dagen? De avondeten-planner van ons huishouden.

- **Week**: elke dag een voorstel uit onze gerechten, bevestigen met ✓ of afwijzen met ✗ (zelf invullen, nieuw voorstel of "we eten niet thuis").
- **Gerechten**: titel, ingrediënten en kooktijd. Toevoegen met de + rechtsboven.
- **Boodschappen**: ingrediënten van de bevestigde dagen, met één knop te kopiëren.
- **Logboek**: wat we de afgelopen 12 maanden gegeten hebben, met export naar XML.

Gehost op GitHub Pages; gegevens en inloggen via Firebase (project `chef-du-buizer-ccf4a`).
Wie toegang heeft staat in `firestore.rules`; plak die regels in Firebase → Firestore → Regels.
